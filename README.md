## 公開中のサイト

**[trade-information](https://trade-information.laravel.cloud/)** は、画面では投資分析と出しています。終値を見て、日足を見比べるサイトです。一覧では終値と騰落で、そのあとチャートと財務を開けます。日足チャートは会員登録すると見られます。2026年に Laravel で公開しました。会員登録は無料です。株価は日足で、取引中の気配は含みません。広告は載せず、[読む人の寄付](https://trade-information.laravel.cloud/donate)で続けています。寄付しなくても、使える機能は同じです。

ログインなしで見られます。銘柄一覧は、会員登録なしで開けます。

| | |
| --- | --- |
| 銘柄一覧 | 日本株と海外市場を、企業名・日本語名・証券コードから探せます。[14,524銘柄](https://trade-information.laravel.cloud/Meigara)で、絞り込みは日本株と米国株。画面では、日本株と FMP 対応の海外市場とも表示 |
| 終値 | ログインなしで、終値と前日からの騰落を見られます。取れない銘柄は「終値なし」と出します。そのあとチャートと財務を開けます |
| 財務 | ファンダメンタルズと需給。画面の案内に出ています |
| 日本株 | 営業日の大引け後に、日足が更新されます |
| 米国株 | 米国上場の銘柄は、ドル建ての終値です |

サイト紹介では、トヨタ自動車、ソニーグループ、Apple、Microsoft の掲載している終値が出ます。

会員になると使えます。会員登録は無料です。登録のあと、次の機能が使えます。

| | |
| --- | --- |
| 銘柄の詳細 | 一覧は誰でも見られます。四本値と日足チャートは、会員登録すると開けます |
| 為替 | 対円レートと、通貨ペアの日足です |
| 取引ルール | 株式とFXの取引時間、決済、銘柄コードです |
| ウォッチ | 見たい銘柄を保存して、比較へ進めます |
| 保有 | 取得金額の割合と損益を残せます |
| 投資メモ | スタンス、目標、損切りを書き残せます |
| 銘柄比較 | 騰落、テクニカル、財務を並べます |
| 資金計画 | 許容損失から株数を計算します |
| 分析ツール | 割安さ、配当、リスク、為替を、入力するだけで計算します。50種類あります |
| 入り方 | パスワードは使わず、メールのログインリンク、パスキー、Google |

掲載している株価は日足です。日本株は営業日の大引け後に更新され、取引中の気配は含みません。日本株以外の株価と、通貨ペアの日足は終値です。板情報、分足、リアルタイムチャートはありません。投資助言や、売買の勧誘は行いません。

寄付は会員画面で、1回または毎月です。毎月はあとから止められます。金額によって、見える機能は変わりません。

## 分析用に作った画面

**[FX 為替マーケットダッシュボード](https://github.com/key-pro/streamlit)** は、Streamlit で作った手元用の分析画面です。`yfinance` から為替を取り、26通貨ペアをタイルで並べます。各タイルには価格、変動率、スパークラインがあり、そこから詳細へ進めます。米国株版は `main_us_stocks.py` から起動します。データには約15〜20分の遅れがあります。

| 分類 | 見られるもの |
| --- | --- |
| トレンド | SMA(20/50)、EMA(20)、ボリンジャーバンド、一目均衡表、DMI/ADX、パラボリックSAR、エンベロープ |
| オシレーター | RSI(14)、MACD、ストキャスティクス、サイコロジカルライン、RCI、移動平均乖離率、ヒストリカル・ボラティリティ |
| そのほか | ローソク足、フィボナッチ、ダブルボトム / ダブルトップや三尊の目視用表示、ダークとライトの切替 |

通貨ペアは、メジャー、クロス円、ユーロクロス、その他の4グループです。画面は `utils` でデータ取得と指標計算、`components` でチャートとゲージに分けています。

## 手元で使うツール

**[PDF統合ソフト](https://github.com/key-pro/PDF_Integration_App)**  
Tkinter の画面に PDF をドロップすると、ファイル名の数字順に並べて1つに結合します。PyInstaller で exe にできます。

**[Django + Docker](https://github.com/key-pro/Django_docker)**  
株価の取得と、scikit-learn による回帰を Django REST framework に載せた構成です。MySQL、Gunicorn、Docker Compose で動かします。
